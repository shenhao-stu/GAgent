# app_cards — 各应用入口参考（按需检索）

> 一张卡 = 一个 App 在真机上**已实证**的最短路径：入口锚点 → 关键控件 → 停点 → 风控。**只写文字锚点和相对位置，不写任何像素坐标**（坐标只能来自当帧 `droid.find/dump/look`）。
> 读法：只检索本次需要的 App 卡片；卡里写「见长档案」时再按需查 `app_scenarios_sop.md`。通用流程见 `phone_use.md`。
> 来源：GAgent-DailyBench v6–v9 的历史真机记录（Pixel 10 / Android 16 为主，魅族 21 / Flyme 为辅）。卡片的版本、入口和耗时可能已变化，以当前观察为准。

## §A 使用这些路径参考

通用观察、工具格式、授权与停点以 `memory/phone_use.md` 为准；卡片仅提供可能的入口锚点。
只检索本次任务需要的卡片，不必全文读取。历史步骤与耗时不是当前界面的保证。
节点有内容但缺少当前弹层时先做视觉确认，不凭相同节点重复点击；`cached: True` 只说明缩略图相近，不能证明任务状态。
已有观察能确定的动作和回读可放在同一轮；满足用户要求即结束。替代渠道必须满足原约束，并明确告知用户。

## §B 设备无关规则（换手机/换系统时仍成立）
- **位置只用相对描述**：顶栏（< 0.12 屏高）/ 底栏 tab（> 0.9 屏高）/ 「第 N 张卡片」/ 「排序条右侧」；需要比例时 `w, h = droid.screen()`。任何把绝对像素写进记忆的行为都是错的（分辨率/密度/刘海/导航栏高度全不同）。
- **小屏或字体大**：同一页面元素更少、需多滚一屏——浏览下方内容用 `scroll_view('down')` 后再观察，浏览上方用 `scroll_view('up')`，不要断言「入口不存在」（v9 菜鸟 3 次误判都栽在这里）。
- **系统版本差异**：Android 13+ 首开 App 会弹「允许通知？」（任务无关点「不允许」）；定位权限三选一（使用时允许 / 仅此一次 / 不允许）选「仅此一次」；Android 12+ 快捷设置用完 `droid.dismiss_shade()`（面板残留会吃掉后续所有 tap）；Android 14+ `accessibilityDataSensitive` 对话框在旧 APK 上 dump 为空壳——见 phone_use_reference.md §0.6。
- **OEM 差异**：系统 UI 包名不同（`com.android.systemui` / `com.miui.*` / `com.huawei.*`），用 `ping().pkg` 判断而不是记包名；OEM 控制中心磁贴常有「图标=开关、文字=进设置」双热区（Flyme 实证）；导航方式（手势/三键）无关——返回一律 `droid.back()`，不点屏幕上的返回区。
- **输入法差异**：搜索/发送优先 `droid.key('ENTER')`；键盘按键位置不可记忆，`look()` 当帧找；剪贴板提示条（Gboard/搜狗样式不同）只认返回里的 `ime_hint`。
- **GA 自身**：浮窗位置随用户拖动变化；Agent 手势期间自动穿透并保持可见，不用任务手势拖动浮窗让路。页面未变时重新观察当前可交互层和目标，不用随机偏移试点；前台变为本次安装的 GAgent 包名时先确认状态，再恢复目标 App。
- **通道纪律**：点名 App 就锁定 App；官网/接口只做**声明过**的兜底（final 第一行写渠道）；`pkgs('别名')` 为空 ≠ 未安装（B站→哔哩哔哩，饿了么→淘宝闪购），按卡上包名 launch。
- **状态驱动与收尾**：动作后等待页面完成并核验，不以固定 sleep 代替观察，不反复重搜或重启。任务结束默认保留已核验页面；只有用户需要退后台时才 `home()` 并核验，`back()` 只是返回上一级。验证码、账号异常或安全验证出现时停手报告；历史成功节奏不保证当前任务可用。

## 生活服务

### 美团 `com.sankuai.meituan` · dump ✅ · 风控 中
- 入口：首页顶部搜索框是**滚动占位词**——点框进搜索页 → `paste(关键词)` → `key('ENTER')`（直接点「搜索」按钮 = 搜占位词）。
- 结果页：顶部频道 tab（全部 / 骑手配送 …）→ 排序条 chips：综合 / 速度优先 / 离我最近 / **好评优先** / 人均价格 / 起送价 / 配送费（**没有「销量」**）；快捷筛选 chips：30分钟送达 / 免配送费 / 减配送费 …。卡片 dump 全字段：店名 / 评分 / 月售 / 预计送达 / 配送费。快捷筛选后**仍会混入超时店** → 逐卡核字段再报。
- 加购到结算：进店 → 商品「+」（规格弹窗选默认）→ 底部购物车「去结算」→ 结算页读「合计」；结算页可能未带地址（红包需选地址）→ 如实说明。**绝不点「提交订单 / 去支付」。**
- 弹窗/风控：首页营销弹窗右上 ✕；「请拖动滑块 / 依次点击图标 / 用最短线连接」= 风控 → **1–2 轮内**如实报告并停手（r28 实证 2 轮/80s），不重试不换路径。风控一旦触发会**跨会话持续十几小时**（搜索/排序一律先弹验证），只有用户本人过一次验证才解除；agent 节奏 6/6 零风控，**脚本式快速冷启 + 连点是诱因**（r27 清购物车脚本连开 3 次即中）。
- 风控预防（本 App 专项，见 §B 通则）：搜索页只提交一次关键词；排序条 chip 点一次即回读，别在几个 chip 间来回点；结果页滚动用 `scroll_view('down')` 一屏一读；进店/加购/结算每步间隔 ≥2s；任务结束 `back()` 回首页或 HOME，不 force-stop；被验证拦住 → 1 轮内报告，等用户本人过验证。
- 实证：L1 19 轮/281s · L2 三约束 28 轮/408s · L3 到结算页 38 轮/562s · L4 含糊指令自决店/款到结算页并问地址 27 轮/386s。

### 淘宝闪购（原饿了么）`me.ele` · dump ❌（自绘，走 look）· 风控 中
- 入口：已登录冷启直达首页（顶部收货地址、搜索框占位词、底栏 推荐/消息/AI点外卖/购物车/我的）；搜索同美团（点框→paste→ENTER）。

### 菜鸟 `com.cainiao.wireless` · dump ✅ · 风控 中（阿里账号）
- 「附近驿站」的**唯一**入口 = 底栏「我的」→ 顶部「常用驿站｜…」卡片；首页 / 取包裹 / 寄包裹 / 发现 都没有（r28 人工逐页核过，不要再翻）。这张卡有两种状态：①账号**未设**常用驿站 → 进「附近驿站」列表（定位用途说明 → 系统定位「仅限这一次」→ 卡片读 名称/地址/距离 → 「重新定位」核验一次；v9 station_L1 25 轮成功走的就是它）；②账号**已设**校园驿站（如 复旦江湾校区 国政路6号）→ 卡片直接打开「选择学校」学生/老师身份页（GuoGuoNewWebViewActivity），**没有附近列表**——此时 1 轮内如实报告「入口被常用驿站占用，需用户在菜鸟里更换/取消常用驿站」，或声明后用高德搜「菜鸟驿站」兜底（高德的营业状态字段陈旧，只报名称/距离），不要在两页之间来回试（v9 L2/L3 各花 8–29 轮才放弃）。
- **点驿站名称 = 一键设为常用驿站**（写动作，无撤销；本机账号就是这么被设成校园驿站的）→ 只读任务只读列表。营业时间列表页不显示，如实说。
- 备选路径（r28 人工探到地址步，未走完）：底栏「寄件券」→ 九宫格「到站寄」→ 寄件表单，寄件方式选「服务点自寄」→ 提示「请先选择寄件地址，方便为您推荐站点」→ 点「地址簿」选**已有**地址（不新建、不填姓名/手机——「编辑地址」表单要姓名+手机号，是个人信息红线）→ 应出现推荐站点（名称/距离）。此路径在寄件流程里，读完站点即退出，绝不点「下单/提交」。该页首次进入会弹国际寄件优惠券浮层，先关 ✕。
- 未登录：「暂不登录，先逛逛」进游客首页，游客只能输单号查物流。
- 实证：L1 25 轮/346s（成功）；L2–L4 因入口误判失败 → 按上面路径走。

### 滴滴出行 `com.sdu.didi.psnger`（8.0.12，华为应用市场，r28 实证 4/4 + r28e 一次误触教训）· 风控 强（真实叫车=真实计费）
- 首开：可能直接跳「支付宝授权（获取手机号）」或本机号一键登录/短信验证码——**登录/授权一律交用户本人**，agent 不点「同意」不填验证码，未登录 ⇒ 一次 ask_user 请本人登录后停。
- 已登录：首页「你要去哪儿」→ paste 目的地 → 候选选完全匹配 → 车型列表读 预估价 / 预计等待（快车 / 特惠快车 / 专车 …）；勾选车型后底部「立即打车 / 呼叫 xx」= 不可逆门，**绝不点**；任务要叫车就在该按钮前 ask_user 一次列齐 起终点/车型/预估价。
- **误触教训（r28e ride_L4）**：想取消「滴滴快车」勾选，直接 tap 了 dump 里 `d='已选中'` 那个**没有 bounds** 的节点 (x≈屏宽 0.93, y≈屏高 0.95)——它就落在底栏「立即打车」大按钮里 → 滴滴真的发起了叫车（幸而其风控验证失败未成单）。硬规则：①**底栏不可逆按钮所在的整条横带（屏高 > 0.9）内，禁止任何坐标点击**，哪怕目标是勾选框/标签；②`dump()` 里没有 `b`(bounds) 的节点其 x,y 不可信，不点；③改选/取消车型只点车型**行内的名称文字**（`tap_text('滴滴快车', exact=True)`）并核对「已选中」数量变化，或先滚动让按钮离开点击区；④点击前用 `find()` 打印目标节点 bounds，确认与 `find('立即打车')` 的 bounds 不相交。多选了车型不影响读价，**宁可不取消**也不要在按钮带上点。
- 兜底：高德「打车」聚合页也能给多平台预估价（其中含滴滴 / 曹操 / T3 等），但用户点名滴滴就先滴滴。

## 系统 / Google 套件

### 时钟（Google Clock）`com.google.android.deskclock`
- 底栏「闹钟」→「+」→ 时间选择器：默认表盘，右下键盘图标切数字输入（小时/分钟分别点）→ 「确定」→ 新闹钟卡片展开：「添加标签」paste → 「重复」勾工作日 chips（周一…周五）→ 铃声/振动不动。冷启若弹通知权限先点掉。设 20 分钟后：以当前系统时间 +20 分钟计算。核验：卡片显示时间+标签+已启用；系统 `next_alarm` 由外部核。

## 敏感 / 只读视觉
### 微信 `com.tencent.mm` — 在册敏感，`dump()` 恒 `[]`，纯截图/GUI，正常导航无固定动作预算（见 phone_use §5）；淘宝 `com.taobao.taobao` dump 空壳走视觉；京东冷启即安全验证 → 停手。
