# 能力索引

按当前用户意图选一项，读取对应说明即可。模块 docstring 是接口真相源；此表不代表权限已授予或服务已配置。

| 任务 | 入口 |
|---|---|
| 手机 App / 网页操作 | `phone_use.md`；App 入口参考 `app_cards.md` |
| 能力初始化与权限 | `onboarding_sop.md`、`capabilities.md` |
| 厂商助手 | `vendor_assistant_sop.md`，仅前台交互 |
| 无线 ADB / shell | `adb_self_setup.md` |
| 虚拟屏 / 后台浏览器 | `offscreen_sop.md`、`vdisplay` docstring |
| 配对电脑 / 电脑工具 | `pclink` docstring、`pc_use_sop.md` |
| 生成 APK | `apk_factory_sop.md`、`apk_design_guide.md`，需自有构建服务 |
| 录屏 / 选照片 | `record_sop.md`、`album_select_sop.md` |
| 看图 | `vision_sop.md` |
| 飞书 / 文档 / 多维表格 | `lark_sop.md` |
| 通知触发 | `notif_trigger_sop.md` |
| 购物比价 | `smart_buying_sop.md` |
| 搜索与事实核查 | `search_source_sop.md`；用户点名 App 时先用该 App |
| 真实世界采集与回忆 | `sense_sop.md`，默认关闭；隐私与回忆细则由该文指路 |
| 持续目标任务 | `goal_mode_sop.md` |
| 记忆整理 | `memory_management_sop.md` |

用户指定渠道优先。登录/验证交用户；对外操作仅按已授权范围执行。不给结果编造数字；缺少证据时说明未完成部分。交付文件放 `temp/` 使用可见文件名，点号或双下划线前缀保留给内部中间文件。
