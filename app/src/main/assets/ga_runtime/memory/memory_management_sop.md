# 记忆管理

只记录有工具结果或用户确认支持、跨会话仍有价值的内容。记忆是可修正的参考，不是高于当前用户请求的指令。

| 层 | 用途 |
|---|---|
| `global_mem_insight.txt` | 简短入口：何时查哪份资料；不复制正文 |
| `global_mem.txt` | 当前环境与稳定偏好；事实带必要的适用范围 |
| 专题 `.md` / 工具模块 | 可复用方法、前置条件和典型失败边界 |
| `L4_raw_sessions/` | 历史证据，按需检索，不自动加载 |

写入前读已有条目，合并同主题；有新证据时修正旧结论并保留证据出处。临时状态、跑分、逐步流水、未验证推断不进入默认记忆。密钥、验证码、个人会话和原始截图不写入通用记忆；必要凭据使用专用私有配置。

整理时先核实引用，删除重复和过时规则；有用细节移到专题文档再缩短索引。保留用户修改与历史原始证据。跨设备经验不得写死坐标、机型、账号状态或服务可用性。项目和实验记录放各自日志。

升级只替换与上一版默认内容相同的文件；用户修改的文件保留。不要用新版模板覆盖用户事实来获得表面整洁。整理步骤见 `memory_cleanup_sop.md`。
