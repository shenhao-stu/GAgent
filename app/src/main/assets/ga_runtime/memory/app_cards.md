# App 入口参考

这些路径来自历史观察，版本、账号和布局可能不同。先读 `phone_use.md`，只检索目标 App；以当帧观察核实入口，不沿用坐标或假设控件树可用。

## 通用核验

- 把查询条件、筛选、排序及终态逐项核对；点击不代表已生效，前两项价格递增也不能证明排序已选中。
- `pkgs()` 的别名搜索为空不证明未安装，可核对实际包名。搜索框占位词不代表已输入，输入后先确认再提交一次。
- 登录、验证码、安全验证与账号异常交用户，不规避风控。只读任务不加购、收藏、修改常用地址、加入会议或提交订单。
- 没有当前可点击范围的节点不能猜坐标；尤其避开与支付、呼叫、发送按钮重叠的目标。发现遮罩、系统面板或 GA 悬浮控件时先确认遮挡。
- 价格须说明规格、数量、优惠条件和时间；不可见字段如实标缺。任务完成保留核验页，用户需要退后台时再返回。

| App / 包名 | 入口与易错边界 |
|---|---|
| 美团 `com.sankuai.meituan` | 搜索页输入后提交；结果按当前排序条和筛选条件核验。配送时间/费用需逐卡读，快捷标签不保证所有结果合格。结算价与列表价口径可能不同。 |
| 淘宝闪购 `me.ele` | 原饿了么；搜索、排序与筛选用当前视觉确认。区分免配送与满额免配送；跨平台对比需同店同规格。 |
| 大众点评 `com.dianping.v1` | 搜索或附近频道按当前入口走；出现验证立即交用户。 |
| 菜鸟 `com.cainiao.wireless` | “我的”中常用驿站可能进入附近列表，也可能进入已有站点/学校页。点击站点可能直接修改常用站点，只读任务勿试点。未登录可用能力以现场为准。 |
| 顺丰 `com.sf.activity` | 运费与时效入口以当前 App 为准；确实不可用后可声明改用官方网站。自绘弹窗可能不在节点结果中。 |
| 高德 `com.autonavi.minimap` | 搜地点核对完整名称/地址；路线核实起终点、出发时间与偏好标签。缺少电话或未来时段信息不得以猜测补齐。 |
| 铁路12306 `com.MobileTicket` | 出发站、到达站、日期→查询；分别核实席别、余票、票价与筛选。只查票时停在查询结果；购票/候补需相应授权。 |
| 携程 `ctrip.android.view` | 目的地、入住/离店日期→酒店筛选/排序。低价可能是床位或有使用条件；明确日期，核实早餐与取消政策。 |
| 滴滴 `com.sdu.didi.psnger` | 起终点→车型、预估价与等待时间；呼叫按钮会下单。改选车型只用当前清晰的行内目标，不能从底栏标签猜点击点。 |

## 系统与文档

- 系统设置/快捷设置按机型当帧观察；磁贴图标和文字可能分别是切换与打开设置。操作后收起面板，再核验实际状态。
- 时钟：`com.google.android.deskclock` 是候选，不保证安装。时间选择器可有键盘入口；核实时间、标签、重复规则与启用状态。
- 日历：`com.google.android.calendar`；核对时区、日期、全天状态、起止时间，保存后回读事件。重复项按用户意图处理，勿覆盖无关事件。
- Google 文档：`com.google.android.apps.docs.editors.docs`，与云端硬盘不同。确认新建/修改目标与保存状态，不因同名默认覆盖旧文档。
