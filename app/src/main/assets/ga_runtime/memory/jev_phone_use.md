# Jev 可选导航定位

Jev 是文本候选选择器，不是聊天模型或截图模型。Base 继续负责用户意图、路径规划、输入文字、授权判断和完成核验。需要单步点击一个可见导航入口但不知道控件准确文字时，可以减少一次 Base 读树选点往返；已经看到唯一准确文字则优先 `jev_ui.click_text(text, package=包名)`，它使用同一保护和执行器，不调用模型。

配置：只在用户授权的手机私有 `files/ga/jev_config.json` 写 `enabled`、`api_key`、`allowed_packages`。模板在 `jev_config.example.json`。不要把 key 打印、发到对话或提交仓库；不要把 Jev 注册为 Chat Completions 服务商。固定 `jev-1.13.0` 与官方 HTTPS 地址。配置不存在、关闭或包名未允许时返回无动作 fallback。允许包名不代表允许该应用内所有操作。

```python
import jev_ui
print(jev_ui.tap('打开显示和亮度设置页面', package='com.android.settings'))
```

使用条件：用户已授权任务、当前处于目标应用、目标只是当前屏幕内的一个导航入口。仍须先读 `phone_use.md` 与 app card。支付、发送、购买、删除、权限授权、账号与设置变更交给 Base 按原规程处理，不能通过此入口执行；文本过滤只是保守辅助，不是授权或完整风险识别。禁止把多个未知页面的判断写成脚本循环。

快路径只选择带可见文字 `t` 的控件，不以图标的 `d` 描述作为导航依据。真机相册曾把画面上的垃圾桶描述为「更多」；图标操作必须由 Base 看图定位并核对实际作用，不能把描述当作授权或真实按钮语义。

每次调用最多一个点击：读取当前单窗口树 → 有界候选 → 一次 Jev 请求 → 分布与时限验证 → 刷新页面 → Android 端再次核对窗口、树和遮挡 → 当前节点 ACTION_CLICK → 读新状态。总选择预算最多 8 秒；网络读取超时可能稍后才返回，晚回复不会继续派发。只支持可读、完整的无障碍树；敏感应用、遮挡、状态变化和旧 APK 不支持保护接口时退出，不偷偷改用旧坐标。

- `fallback` 且 `action_dispatched=False`：未提交动作，Base 重新观察后决定原路径。
- `observed`：动作已提交并取得新观察；`observation_changed` **不代表任务完成**。必须用页面目标或独立终态核验；无变化不自动重试。
- `visible_text` 是点击后重新读取的页面文字，可直接用于核对标题和目标字段；信息已充分时不要重复 dump 或重复读规程。返回空壳过渡页时工具只做有限次数观察，不增加点击。
- `uncertain` 或 `action_dispatched=None`：可能已经提交；先检查当前状态，不能重放。
- 取消沿用 `run_guard`，取消异常不吞掉。已交给 Android 的动作无法撤回；二次复核也不能完全消除并发 UI 变化。

返回分项 API 用量与耗时、候选和紧凑新页面文字。完整观察、请求、响应、动作回执保存在私有 `temp/jev/<id>.json`（无 API key）；模型供应商只接收目标和候选文字。没有图片或隐藏推理采集。使用云服务前应确认相应屏幕内容允许发送。训练导出时保留本地原件、单独脱敏公开投影；Base 与 Jev Token 分项统计，缺失为未知。

精确入口和 Jev 入口都调用当前绑定节点的 `ACTION_CLICK`，日志 `method=node_click`；`action_result` 仅为 Android 回执，false/异常不会补发坐标手势。旧 `tap`/`tap_text` 的行为保持兼容。Base 与 Base+Jev 对比必须在同包同执行器上完成，不把节点点击改进归因于 Jev 权重。
