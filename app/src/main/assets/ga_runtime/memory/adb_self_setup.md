# 无线调试自连 SOP（给 GAgent 补 shell 能力）

自连本机「无线调试」, 拿 A11y 够不到的 shell 能力(`input -d/am/pm/wm/screencap -d/dumpsys` 等, 虚拟屏模式的前置)。**无 root、无 Shizuku**; app 绝不静默开, 全程用户授权。
> 改 system/secure settings(亮度/音量等)必须走 `adb_shell "settings put ..."`: GA app 身份的 `settings`/`content` 命令会报权限错(INTERACT_ACROSS_USERS / ACCESS_CONTENT_PROVIDERS), 只有 shell 身份能写。

> 飞书/lark 任务**永不需要 ADB**——走 `lark_sop.md` 的 `lark_native`(纯端内 requests)。

## 前提
开发者选项已开(未开: 设置→关于→连点版本号 7 次)。系统硬闸, 只能引导用户手点。

## 三步(设置页「无线调试自连」一点即走引导)
1. **开发者选项 → 无线调试 → 打开**(弹窗点**允许**)。GA 深链只到开发者选项页, 「无线调试」入口需用户自己点进去——这是最易卡的一步, 引导话术要指明位置。
2. **「使用配对码配对设备」**: 弹窗给 6 位码 + IP:配对端口 → `droid.adb_pair(码, 配对端口)`。**仅首次**(证书持久化)。⚠配对期间弹窗必须保持前台, 关掉即作废。
3. **连接**: `droid.adb_connect()`(**无参**, 自动发现连接端口: 上次成功端口→5555→mDNS), 不用手填/OCR 那个每次都变的端口。之后 `droid.adb_shell("...")` 可用。

## 校验与自愈
- 校验: `droid.adb_status()` → `connected:true`(libadb 派生真值, 无假态); `adb_shell("echo ok")` 回 `ok`。
- `adb_shell` 断线**自动重连重试**(非幂等命令不重复执行); 端口变了下次调用自动 mDNS 重发现, 一般无需手动干预。单条命令失败(超大输出/卡住)只失败这一条, **不代表连接死**, 勿据此重配对。
- 无线调试被用户关掉: 引导重新打开即可, 不必重新配对(证书还在)。

## 大输出三禁(拖垮/超时元凶)
- ⚠禁 `| head`(提前关管道无 EOF 拖到超时); 截断用 `head -c N`/`sed -n '1,Np'`/落文件分段读。
- 输出超 `max_bytes`(默认 256KB)**报错**不静默截断; 按提示分页, 大二进制显式调大 `max_bytes`。
- 长驻命令(`top`/`logcat -f`)用 `adb_shell_detached`, 禁 `adb_shell`。

## 排障铁律
- **服务状态唯一判据 = `droid.ping()`**。bus_port.txt 是内部实现(code_run cwd=temp 下相对路径恒看不到), 禁用文件存在性判断"核心服务"状态; ping 不通=总线组件未监听(重启 App 恢复), 与 agent 是否运行无关。
- mDNS 发现失败的最后兜底=OCR 设置页读连接端口: **必先**观察确认当前是系统设置的无线调试页, 绝不 OCR GA 自己的对话页(曾读到旧端口空转); 读到再 `adb_connect(端口)`。
- 无障碍能读到配对弹窗时 GA 自动填码; 读不到就照弹窗让用户填一次(不猜、不爆破)。

## 红线
- 配对码/端口只用于本机 `127.0.0.1` 自连; 码/token 不入日志、不入帖子。
- **「打开开发者选项 / 打开无线调试 / 发起配对」是用户专属动作**: agent 不得用 GUI 自动化替用户点开——**即使用户说「自主决策、别再问我」也不行**(那是对任务路径的授权, 不是对提升调试权限的授权)。
  实证(2026-09-03 Pixel 10 bench aw_font_scale): agent 问了一次、被"自主继续"后自己进设置搜「无线调试」→开开关→点「配对」→从 dump 读码配对, 用 17 轮拿到 shell 写 font_scale。
  正确做法: 用户不开无线调试 ⇒ 走普通 App 界面完成(Pixel 的字体/音量/亮度 GUI 路径都可用, 按 phone_use.md 当帧观察), 或如实报告"需要你先打开无线调试"后停下。
- 无线调试用完不必关(用户资产), 但**绝不**替用户关闭/开启该开关本身。
