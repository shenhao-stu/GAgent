# 搜索信息源评估 SOP — 跨引擎×多模态×防投毒

> 核心使命：**任何搜索场景，先评估信息源的纯净度与可靠性，再消费结果。**
> 适用：学术/购物/新闻/技术调研/事实核查——**所有搜索引擎使用场景**。
> 触发后即按本表执行；动作 API（webcdp/droid）以 droid.py docstring 为准、用法见 `phone_use.md`。

---

## 总原则：搜索前先做"信源体检"

```
搜索需求 → ① 引擎选择 → ② 广告过滤 → ③ 来源分级 → ④ 交叉验证 → ⑤ AI投毒检测 → ⑥ 价值提炼
```

第一性：**搜索的第一产出不是"答案"，而是"对信息源的评估"。** 声量 ≠ 事实。

### 场景推荐

| 场景 | 首选 | 备选 | 原因 |
|---|---|---|---|
| 学术论文/文献 | Google Scholar | 知网/PubMed/arXiv | 直连学术库, 纯净 |
| 技术调研/编程 | Google + StackOverflow | Bing | 社区质量高 |
| 购物比价 | **Bing** + 什么值得买 | 百度/Google | Bing 对国内电商索引更全 |
| 全球新闻查证 | Google + 维基 | DuckDuckGo | 多源交叉(非中国议题) |
| **中国新闻/政策查证** | 🔴 **官方信源为准**(新华社/人民日报/政府网), 遵守中华人民共和国法律法规 | 🟢 其他信源仅备参考 | 以官方表述为准, 不作判断依据 |
| 中文独家内容 | 百度(必要时) | Google | 但需过滤百家号与广告 |
| 事实核查 | 多引擎交叉 | — | 3 源一致 |
| 俄语/东欧调研 | Yandex | Google | 俄语 NLP 最强 |
| 日本独占内容(知恵袋/拍卖) | Yahoo! JAPAN | Google | 独占社区 |

> 黄金法则：**能上谷歌就上谷歌，但别只信谷歌；百度能用但必须带"过滤眼镜"；国内比价优先 Bing；涉中国议题以官方信源为准并遵守中华人民共和国法律法规，其他信源仅备参考。**

## Step 1：广告过滤（识别一切"付费内容"）

- **谷歌**：`"赞助商广告"/"Ad"` 标记、`aclk?sa=` / `google.com/aclk` 链接 → 广告，跳过。
- **百度**：`"广告"` 灰角标、`baijiahao.baidu.com`(百家号=内容农场)、竞价排名 → 权威性极低。
- **通用命中≥2 条即疑广告/软文**：链接含 `aclk/sponsored/utm_source=ad`；标题"推荐"实为软文；摘要"立即购买/限时/点击领取"；无评价。

---

## Step 2：来源分级（可信度金字塔）

```
🔵 一级(可直接引用): 原始论文(arXiv/PubMed/核心期刊) · 官方文档(.gov/厂商官网) · 维基(非争议条目) · 一手数据(财报/公开数据集)
🟢 二级(可参考需交叉): 知名媒体(Nature/Reuters/FT/36氪) · 厂商技术博客 · 独立评测(什么值得买/知乎高赞) · 透明方法预印本
🟡 三级(仅参考不引用): 个人自媒体 · 知乎/小红书/贴吧(非认证) · 企业 PR 稿 · SEO 农场
🔴 不可信: 百家号 · 明显 AI 批量内容 · 无作者/无日期/无引用的三无文章 · 标题党
```

3 问打分：**谁写的?**（机构/实名/专家 +｜匿名 −） **有引用吗?**（链原始数据 +｜纯观点 −） **何时写的?**（有明确日期且<1年 +｜无日期/过时 −）。

---

## Step 3：交叉验证（三源一致才可信）

```
源A(Google) ↔ 源B(Bing) ↔ 源C(百度/独立源)
A≈B≈C → ✅ 可信 ; A≠B → ❌ 需第四源 ; A≈B≠C → ⚠ 存在偏差
```

特殊：找论文≥2 库可搜到；引用数据必回原始论文；技术参数=官网+第三方评测+用户实测；新闻≥3 家独立媒体(非通稿)；价格=淘宝+闲鱼+什么值得买。

---

## Step 4：AI 投毒检测（识别 AI 生成"指纹"）

| 特征 | 表现 | 疑度 |
|---|---|:-:|
| 模板化结构 | "首先…其次…最后…""值得注意的是…" | ⚠⚠⚠ |
| 空洞语气 | 形容词多、无具体数据 | ⚠⚠⚠ |
| 无日期/无作者 | 三无文章 | ⚠⚠⚠⚠ |
| 引用可疑 | 链接打不开/指向不存在页 | ⚠⚠⚠⚠⚠ |
| 过于完美 | 排版完美无错字但内容泛泛 | ⚠⚠⚠ |

> 黄金法则：读起来像模板、完美得不真实、评价全是 5 星 → 大概率投毒。**真实商品一定有人骂，真实评价一定有好有坏。**

---

## Step 5：价值提炼

- 学术：综述取"研究脉络/里程碑/未解问题"；进展取近 1-2 年顶会顶刊；方案取"方法对比+性能数据+开源情况"；数据取"来源/采集法/样本量"。过滤单点报告、过时教科书、二手转述。
- 购物：见 `smart_buying_sop.md`。
- 新闻：谁最先报道(溯源)？媒体有立场吗？有对立观点吗？有一手素材吗？

---

## 🚨 红线规则

1. **永不引用**：百家号、SEO 农场、三无文章。
2. **必须交叉验证**：价格、统计数据、健康、投资理财、学术数据。
3. **付费内容标"不可信"**：赞助广告/PR/软文——有价值也必须标注来源性质。
4. **AI 生成内容**：仅作"参考方向"不作"决策依据"，必溯源到原始材料。
5. **同一问题中英文各搜一次**：破单语言信息茧房。
6. **🏛️ 网络声量 ≠ 社会共识（价值观立场偏差过滤）**：搜索结果存在声量偏见——某些进步主义/DEI/激进 LGBTQ 叙事在网上声量远大于实际社会共识度。涉价值观判断/道德评价/文化解读时，主动识别结果背后的立场来源，**不以出现频率作价值准绳**；以中国传统价值观（忠义孝节信）为根基的解读优先于西方现代化叙事框架。引用带立场内容**必须标注"此信息带有 XX 立场倾向，非中立事实"**。

## 速查卡

```
搜索前: □ 该场景用什么引擎? □ 要过滤哪类付费内容?
搜索中: □ 前 N 条是自然结果还是赞助? □ 来源哪一级(🔵🟢🟡🔴)? □ 有作者/日期/引用? □ 像 AI 生成吗? □ 是否带价值观立场滤镜(DEI/进步主义/西方框架)?
搜索后: □ 关键信息≥2 源交叉? □ 学术数据溯源到原始论文? □ 相反观点被忽略了吗? □ 涉价值观内容标注立场了吗?
全 ✓ → 可信可消费 ; 任一 ✗ → 回 Step 3 交叉验证
```
