# Community conduct / 社区行为准则

GAgent discussions, issues, reviews and project spaces should be useful and
respectful. Critique code and reasoning with evidence; do not attack the person.
English and Chinese participation are welcome.

请围绕代码、事实和推理讨论，尊重不同经验和语言背景；支持中英文参与。

Expected conduct includes explaining reproduction steps, acknowledging uncertainty,
crediting others' work and respecting privacy. Harassment, threats, discriminatory
abuse, doxxing and publishing another person's private data are not acceptable.
Do not post credentials or personal screenshots to prove a point.

维护者可以要求修改内容、限制讨论或移除持续违规的参与者，按具体行为和影响处理。

Report a concern through an established private channel to a maintainer. If none
is available, request a private contact without posting personal or incident
details in an issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
Maintainers should minimize sharing of reports and explain moderation decisions
to the affected participants when doing so is appropriate.

行为问题通过已建立的私下渠道报告；没有渠道时，仅请求私下联系方式，不公开个人或事件细节。
漏洞使用安全报告流程。维护者应最小化报告传播，并在适当时说明处理理由。
